Dana hanya kembali lewat Cancel (sebelum ada hasil kerja) atau dibayar ke worker lewat Approve yang kamu konfirmasi sendiri di wallet. Cara kerja & keamanan
  • Login hanya lewat wallet kamu sendiri (Binance Wallet / MetaMask). Tidak ada login QR di web, tidak ada pairing code, tidak ada seed phrase / private key yang diminta — jangan pernah berikan itu ke siapa pun.
  • Setiap pergerakan dana adalah transaksi yang kamu konfirmasi sendiri di wallet. Tidak ada transfer otomatis / terjadwal.
  • Kontrak tidak memungut fee dan owner tidak bisa menarik dana pengguna. Dana escrow hanya bisa keluar lewat Approve (ke worker) atau Cancel (kembali ke poster).
  • Agent ID di sini dipakai sebagai gerbang akses (cek balanceOf di kontrak Agent ID). Aplikasi ini bukan alat untuk mencari wallet orang lain berdasarkan nama.
